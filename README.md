## Overview Data Warehouse Project

This project demonstrates an end-to-end ETL pipeline and Data Warehouse implementation using the Vehicle Loan Default Prediction dataset.

## Tech Stack

- Python
- Pandas
- PostgreSQL
- Supabase
- SQL
- Google Colab
- pgAdmin 4

## Architecture

Raw Dataset
↓
ETL Pipeline
↓
Star Schema
↓
PostgreSQL Data Warehouse
↓
Analytics

## Data Model

- Fact Table
  - fact_loan

- Dimension Tables
  - dim_customer
  - dim_branch
  - dim_date
  - dim_employment
  - dim_credit_score

## Features

- Data Cleaning
- Data Transformation
- Star Schema Modeling
- Incremental Load Simulation
- SQL Analytics

## Dataset

Vehicle Loan Default Prediction Dataset (Kaggle)
